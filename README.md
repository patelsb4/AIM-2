# AIM-2
The analysis examines the effects of extreme heat on emergency department visits among late postpartum individuals enrolled in Medicaid in Philadelphia (2016–2019).

Scripts:
1_claims_clean3.R: Loads and cleans emergency department visit data for the pregnant and postpartum Medicaid population in Philadelphia (2016–2019).
1_tempcleaning.R: Loads and cleans city-level temperature data in Philadelphia (2016-2019)
2_cts3.R: Defines functions to (1) create aggregated analytic datasets and (2) implement the DLNM used to estimate the association between extreme heat and ED visits
